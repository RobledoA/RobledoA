## 📂 Featured AI Deliverables

- 📚 **Study RAG (Groq):** Local-first RAG app for studying — upload PDFs/DOCX/TXT/EPUB, index them with local embeddings + ChromaDB, and ask questions answered strictly from your own material, with cited sources. Deployable to Hugging Face Spaces.
- 🧠 **RAG Architecture Notes:** Documented pipeline design — from document processor → chunking → embedding model → vector DB → retriever → Groq LLM → grounded answer.
- 🔧 **Deployment Troubleshooting Playbook:** Hands-on notes on shipping a Gradio app to Hugging Face Spaces — dependency conflicts, SDK versioning, and hardware configuration pitfalls (and how to avoid them).
